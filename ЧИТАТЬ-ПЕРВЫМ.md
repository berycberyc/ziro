# Экран «Қадамдар» — порядок установки

## 1. Сначала миграция

Supabase → SQL Editor → New query → вставить целиком содержимое
`supabase/059_session_steps.sql` → Run.

Если номер 059 у вас уже занят, переименуйте файл в следующий свободный —
содержимое менять не надо.

Миграция создаёт одну таблицу `session_steps`: там хранятся галочки,
которые вы ставите рукой. Ничего существующего она не трогает.

## 2. Потом файлы

Два файла, структура папок как в архиве:

```
app/admin/steps/page.tsx     ← новый, сам экран
app/admin/layout.tsx         ← заменить существующий
```

В `layout.tsx` изменена **одна строка** — в меню добавлен пункт
«Қадамдар» первым. Если вы правили это меню после того, как я его читал,
не заменяйте файл целиком, а допишите строку руками:

```ts
{ href: "/admin/steps", label: "Қадамдар" },
```

## 3. Деплой и жёсткое обновление

После выкладки — Ctrl+Shift+R.

## Как это работает

Выбираете сессию — получаете 20 шагов тремя блоками: подготовка,
день теста, после теста. Название шага это ссылка на экран, где он
делается.

**Галочки двух видов.**

Где написано «өздігінен» — система смотрит в базу сама, вручную отмечать
нечего. Таких шагов девять:

| Шаг | Что проверяется |
|---|---|
| Сессия деректерін толтыру | дата, время начала, адрес, цена заполнены |
| Сұрақтарды жүктеу | сколько пар «предмет + вариант» залито из нужных |
| PDF-терді кері салу | сколько PDF загружено; Тілдер считается за один файл |
| Төлемдерді растау | сколько броней подтверждено из всех |
| Нұсқа, аудитория, орын қою | у скольких офлайн-учеников всё заполнено |
| Онлайн жауаптарды жинау | есть ли собранные онлайн-ответы |
| ZipGrade файлдарын жүктеу | по скольким предметам загружен экспорт |
| Нәтижелерді жариялау | есть ли строки в `published_results` |
| «Нәтиже дайын» белгісі | флаг `has_results` у сессии |

Эти шаги ещё и пишут, чего именно не хватает: «нет: Математика 3,
Сандық 1», «5 учеников без варианта, места или ZipGrade ID».

Остальные одиннадцать — ручные: напечатал, разложил по партам, собрал
бланки, проверил сырые ответы, посчитал. Этого база знать не может.

**Умные пропуски.** Если в сессии нет онлайн-участников, шаг «собрать
онлайн-ответы» сразу считается пройденным с пометкой «в этой сессии
онлайна нет». Так же с ZipGrade, если нет офлайн-участников.

## Что можно поменять без меня

Весь список шагов лежит в начале `page.tsx` в массиве `STEPS`. Каждый
шаг — это название, подсказка и ссылка. Переставить порядок, поменять
текст или убрать лишний шаг можно прямо там, остальной код трогать не
надо.
